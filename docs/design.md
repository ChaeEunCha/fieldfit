## 1. 디자인 컨셉

- **톤앤매너**: 흙·나무·수확을 연상시키는 웜톤(크림 베이지 + 짙은 녹색 + 브라운) 팔레트로 "귀농·재배"라는 도메인을 시각화.
- **폰트**: 한글은 Pretendard, 라틴 문자는 Manrope를 우선 사용하는 이중 폰트 스택.
- **디바이스 프레임**: 모든 화면이 390×844(iPhone 계열 뷰포트) 프레임 안에 표현되어 모바일 우선(Mobile-first) 설계임을 명시.
- **정보 밀도**: 카드형 레이아웃 + 진행률 바/뱃지/이모지 아이콘으로 전문 용어 없이 직관적으로 정보 전달(PRD 6절 "전문 용어 최소화" 원칙과 일치).

## 3. 화면 목록 및 PRD 기능 매핑

와이어프레임은 총 6개 화면으로 구성되며, PRD(`필드핏_PRD.md`)의 F1~F9 기능과 아래와 같이 매핑됩니다.

| # | 화면명 | 대응 PRD 기능 | 비고 |
|---|---|---|---|
| 01 | 입력 화면 | F1 온보딩(지역·작물 입력) | 작물 **복수 선택** UI로 설계되어 F4(매트릭스)와 자연스럽게 연결됨 |
| 02 | 진단 결과 화면 | F3 적합도 산출 결과 + F4 비교 매트릭스 | 별도 매트릭스 화면 없이 **랭킹 리스트 형태로 통합** (기획서상 매트릭스/레이더와는 다른 구현안) |
| 03 | 재배 가이드 리포트 | F5 LLM 재배 가이드 리포트 | "적합도 근거 / 개선 방안 / 시기별 위험 경고 요약" 3단 구성 |
| 04 | 위험 경고 캘린더 | F7 위험 경고 캘린더(.ics) | 월간 캘린더 + 다가오는 위험 리스트 + .ics 다운로드 버튼 |
| 05 | 챗봇 화면 | F6 컨텍스트 챗봇 | 답변마다 "📄 근거: OO" 출처 태그, 하단 추천 질문 칩 |
| 06 | 종합 홈/대시보드 | F9 마이페이지(확장) + 신규 홈 화면 | PRD의 IA에는 없던 **홈 대시보드**가 신규 진입점으로 추가됨 |

### 3.1 PRD 대비 주요 차이점 (구현 시 확인 필요)

- **F2(공공데이터 연동 로딩 화면)**: 6장 와이어프레임에는 별도 로딩 화면이 없음. 02번 화면 진입 전 로딩 애니메이션을 오버레이/트랜지션으로 추가할지 결정 필요.
- **F4(5작물 비교)**: 기획서는 매트릭스/레이더 차트를 제안했지만 와이어프레임은 랭킹형 리스트(카드+막대그래프)로 구현. 어떤 안을 채택할지 확정 필요.
- **F8(알림 수신 시점 설정)**: 04번 화면에 알림 옵션(당일/1일 전/3일 전/7일 전) 선택 UI가 보이지 않음 — `.ics 다운로드` 버튼만 존재. 알림 시점 선택 모달을 별도로 추가해야 함.
- **F9(마이페이지/진단 이력)**: 별도 이력 리스트 화면 대신 06번 홈 대시보드에 "나의 진단 작물" 카드 그리드로 축약되어 표현됨.
- **하단 탭 내비게이션**(홈/진단/캘린더/챗봇)이 06번 화면에서 처음 등장 — 전체 IA에 탭 기반 내비게이션을 추가할지 결정 필요.
- **F10(밭 구역 관리, 신규)**: 이 와이어프레임(6장면) 제작 이후에 추가로 결정된 기능이라 원본 와이어프레임에는 없음. 06번 대시보드에 "나의 진단 작물" 카드와 함께 구역 그리드 섹션이 추가될 예정 — 상세 컴포넌트 설계는 구현 단계에서 별도 진행. 기능 상세는 `필드핏_통합기획문서.md` 15장 F10 참고.

## 4. 화면별 상세 설명

### 01 · 입력 화면 (F1 온보딩)
- **헤더**: `F` 그라디언트 로고 배지 + "FieldFit" 워드마크
- **타이틀**: "재배 예정지와 작물을 알려주세요" / 서브카피 "공공데이터 기반으로 환경 적합도를 진단해요"
- **재배 예정지 입력**: 원형 위치 아이콘 + placeholder "주소를 검색하세요 (예: 충북 제천시)" + 우측 "검색" 텍스트 버튼
- **작물 선택(복수 선택 가능)**: 3열 그리드 카드(사과🍎·배🍐·오이🥒·감자🥔·상추🥬), 선택 시 연녹색 배경(`#E9F0E2`) + 그린 테두리 + 우상단 체크 뱃지
- **하단 CTA**: "진단하기" 그라디언트 버튼(화면 하단 고정)

### 02 · 진단 결과 화면 (F3 + F4)
- **상단**: 지역명 캡션("충북 제천시 봉양읍") + 타이틀 "환경 적합도 진단 결과"
- **작물별 랭킹 카드 리스트**: 순위 뱃지(1~4) + 작물 이모지 + 작물명 + 진행률 바 + 점수(예: 사과 82점 1위, 감자 75점 2위, 상추 61점 3위, 오이 48점 4위·비활성 처리)
- **산출 근거 데이터 박스**(1위 작물 기준): 평균 기온 11.4℃ · 연 강수량 1,320mm · 토양 pH 6.2 · 일조 시간 2,180h — 2×2 그리드
- **하단 CTA**: "사과 재배 가이드 보기 →"

### 03 · 재배 가이드 리포트 (F5)
- **헤더**: 작물 이모지 + "OO 재배 가이드" + 캡션 "AI가 생성한 맞춤형 리포트 · 지역명"
- **섹션 1 "적합도 82점의 근거"**: 온도대·토양 조건에 대한 서술형 설명(예: 서리 발생 빈도 언급)
- **섹션 2 "개선 방안"**: 번호 매긴 리스트 3항목(석회 시용, 서리 방지 시설, 배수로 정비)
- **섹션 3 "시기별 위험 경고 요약"**(경고색 박스): 월별 리스크 요약 3줄(4월 초/6월 중/8월 말)
- **하단 CTA**: "위험 캘린더로 보기 →"

### 04 · 위험 경고 캘린더 (F7)
- **헤더**: "위험 경고 캘린더" + 캡션 "사과·오이·감자·상추 통합 일정"
- **월 네비게이션**: `‹ 2025년 4월 ›`
- **캘린더 그리드**: 7열(일~토), 위험일(5일)은 배경 `#FDECE8`+테두리 강조+이모지(🍎❄️) 표시
- **다가오는 위험 일정 리스트**: 날짜 배지 + 제목("🍎 사과 서리 주의보" 등) + 설명, 위험 유형별 색상 구분(저온=적, 병해=황, 가뭄=브라운)
- **하단**: 우측 정렬 아웃라인 버튼 "⬇ .ics 파일 다운로드"
- **주의**: 알림 수신 시점(F8) 선택 UI는 이 화면에 없음 — 별도 추가 필요

### 05 · 챗봇 화면 (F6)
- **헤더**: 🌾 아이콘 배지 + "FieldFit 어시스턴트" + 캡션 "리포트 근거로 답변해요"
- **대화 영역**: 사용자 말풍선(우측 정렬, 그린 그라디언트) / 봇 말풍선(좌측 정렬, 흰 배경 + 테두리)
- **근거 태그**: 봇 답변 하단에 점선 구분선 + "📄 근거: 재배 가이드 리포트 · 토양 데이터" 형태로 출처 명시(F6 예외처리 요구사항과 일치)
- **추천 질문 칩**: 가로 스크롤 칩("서리 위험은 언제까지?", "사과 점수 근거는?")
- **입력창**: placeholder "질문을 입력하세요" + 원형 전송 버튼(↑)

### 06 · 종합 홈/대시보드 (신규 · F9 확장)
- **헤더**: 인사말("안녕하세요 👋 김농부님의 농장") + 알림 벨 아이콘
- **메인 요약 카드**(짙은 그라디언트): 지역명 + 1순위 작물·점수(🍎 사과 · 82점) + 2·3순위 점수 미니 뱃지
- **다가오는 위험 알림**: 리스트(❄️ 사과 서리 주의보 D-9, 🦠 오이 병해 경보 D-65) + 우측 "전체보기" 링크
- **나의 진단 작물**: 2열 그리드 카드(작물 이모지 + 이름 + 점수)
- **하단 CTA 2버튼**: "+ 새 진단하기"(아웃라인) / "💬 챗봇에게 묻기"(그라디언트)
- **하단 탭바**: 홈🏠(active) · 진단📊 · 캘린더📅 · 챗봇💬
